# Клуб «Фишка»

Мини-приложение с четырьмя казино-играми, чтобы убить время. Только виртуальные фишки, без реальных денег.

- **Блэкджек**: 6 колод, дилер стоит на 17, удвоение, блэкджек платит 3:2.
- **Покер**: видеопокер Jacks or Better (9/6), держите карты и добирайте.
- **Рулетка**: европейское колесо (37 лунок), ставки на числа, цвет, чёт/нечет, дюжины, колонки.
- **Слоты**: 3 барабана, одна линия, три семёрки ×200.

Баланс, число раундов и лучший выигрыш хранятся в `localStorage` на устройстве.

## Запуск

Это один файл `index.html` без сборки и зависимостей. Откройте его в браузере или раздайте любым статическим сервером:

```sh
python3 -m http.server 8000
```

## Как Telegram Mini App

Приложение подключает `telegram-web-app.js`: в Telegram оно разворачивается на весь экран, использует системную кнопку «Назад» и виброотклик.

1. Опубликуйте `index.html` по HTTPS (например, GitHub Pages: Settings → Pages → ветка с файлом).
2. В [@BotFather](https://t.me/BotFather): `/newapp` (или `/mybots` → Bot Settings → Menu Button) и укажите URL страницы.
